# Mistakes｜认知错误与复测

当前没有已关闭的正式错题。下面记录需要警惕的认知风险，等 API Question 1 Review 后再升级为正式错误记录。

## 观察中的风险

### M-001 把未来规模当成当前必做项

- 表现：在没有流量、数据量和故障证据时，提前引入分布式或拆分。
- 风险：过度设计，训练偏离约束递增。
- 复测点：API Question 1 是否能区分“现在必须确定”和“以后再决定”。

### M-002 把知道技术当成掌握架构

- 表现：讨论组件名称，而不是“为什么现在需要 / 不用会怎样 / 代价是什么”。
- 复测点：后续 ADR 是否能写清 Trade-off。

## 记录格式

以后每条正式错误包含：

- 错误是什么
- 在哪个任务/项目中出现
- 正确约束是什么
- 如何复测
- 是否已经纠正
