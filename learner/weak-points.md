# Weak Points｜当前短板

只记录当前仍然成立的短板，不堆历史。

## 1. 架构方法论尚未稳定

能感觉到“以后可能会重构”，但还不能稳定地用同一套问题把设计问清楚：

- 核心对象是什么？
- 当前约束是什么？
- 为什么现在需要？
- 不用会怎么样？
- 替代方案和代价是什么？

## 2. 容易把未来可能性当成当前约束

已经会提前考虑分布式、区域划分、数据规模。下一步要训练：没有真实约束时，哪些决策现在必须做，哪些必须延后。

## 3. 缺少项目证据

本仓库还没有可运行项目、实验、ADR 和 Experience Card。因此没有任何能力可以升到 L3。

## 4. 结构化表达与答辩不足

需要把设计讲成可审查、可追问、可迁移的架构叙述，而不是实现说明。

## 5. 可靠性与演进细节待验证

错误模型、幂等、兼容性、版本、鉴权、可观测性是否能主动纳入设计，要等 API Question 1 的作答来验证。
