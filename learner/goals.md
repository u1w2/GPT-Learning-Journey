# Goals｜成长目标

## North Star

找到能力边缘，把模糊判断练成可重复的架构方法，再适当扩展，最终成为：

> 能独立做系统架构，并具备 AI 系统设计经验的高级架构全栈师。

不是学完 10 门课。不是先成为传统架构师再临时补 AI。

## 近期

完成 API Question 1 的独立作答。用这次作答探测主边缘：

> 现在必须冻结什么，什么必须延后。

Review 后把设计动作标成 Sharp / Fuzzy / Blind。下一题打最大的 Fuzzy。

## 中期

在真实约束下完成至少一个完整项目闭环，并把当前主模糊点练成 Sharp：

```text
设计 → 实现 → 实验 → 暴露问题 → Root Cause → 解决 → ADR → Experience → 答辩
```

至少一项能力升到 L3，且有项目证据。
扩展仍以全栈契约、数据、可靠性为主，不提前开云原生 / Agent 专题。

## 长期

能够独立完成，并迁移到含模型组件的系统：

```text
看到业务
 → 识别核心对象 / 流程 / 客户端
 → 识别约束与风险
 → 比较方案
 → 选择并验证
 → 知道何时推翻
 → 能把模型当系统组件来设计：评测、降级、责任边界、数据闭环
```
