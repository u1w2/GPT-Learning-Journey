# Learner State｜个人成长状态

本目录用于记录当前学习者的个人能力、进度、评估、错误和成长历史。

## 核心文件

- `profile.md`：学习背景、经历、技术栈与目标
- `capability.md`：能力等级与证据
- `progress.md`：当前阶段、已完成任务和下一任务
- `assessment.md`：阶段性 AI / 人工评估
- `mistakes.md`：错题、认知错误与复测结果
- `weak-points.md`：当前能力缺口
- `goals.md`：近期、中期和长期目标
- `sessions/`：学习过程记录

## 状态原则

Learner State 不是简单的打卡记录，而是 AI 判断“这个人目前真正会什么、不会什么、为什么不会、下一步应该训练什么”的长期状态。

## 隐私

这是个人学习数据目录。仓库当前采用 Private-first / Open-source-ready 设计。未来如需公开课程内容，可通过忽略个人状态目录或建立公开镜像仓库实现隐私隔离。
