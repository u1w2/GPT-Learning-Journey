# Templates｜标准模板

所有项目、实验、问题和经验尽量使用统一结构，便于 AI 检索和长期积累。

## 推荐模板

- Project Template
- Capability README
- Test Lab Experiment
- Problem Reproduction
- Solution Record
- Architecture Decision Record
- Limitation Record
- Experience Card
- Interview Question Mapping
- Learner Assessment
- Mistake / Retest Record

## 设计要求

模板必须服务于“经验形成”和“能力评估”，避免为了文档完整而产生无价值的重复记录。
