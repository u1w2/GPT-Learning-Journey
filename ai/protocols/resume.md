# Resume｜新窗口如何接上

对话窗口没有长期记忆。Git 才有。

## 新窗口能不能连续？

能。连续的是仓库状态，不是聊天记录。

新窗口第一句用：

```text
继续 GPT-Learning-Journey
```

然后 Cursor 必须先读 `learner/CURRENT.md`、缺陷队列和最近 git log，从当前任务继续。禁止重新开始课程。

## 要不要一直留在旧窗口？

不必。一个学习节点 commit 之后，下一次用新窗口更好。

旧窗口越聊越长，上下文会被截断或摘要，细节会丢。
新窗口不自动带着旧聊天，但会重新读取 CURRENT，这比依赖长对话压缩更稳。

## Token

- 新窗口：不加载整段旧聊天，只加载当前文件。通常更省，也更干净。
- 旧窗口：前期省一次“重新读文件”，后期上下文膨胀，质量和费用都会变差。
- 不要每说一句就开新窗口。以“一个学习节点”为单位切换。

## 不要做的事

- 不要把整段旧对话贴进新窗口
- 不要在新窗口说“我们重新规划一下学习体系”
- 不要以为新窗口会记得你上次没写进 Git 的口头结论
