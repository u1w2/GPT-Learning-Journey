# Curriculum｜能力成长体系

本目录定义“应该具备什么能力”。每个阶段 README 是可执行成长协议，不是教材目录。

## 能力结构

```text
01 Engineering
→ 02 System Design          ← 当前
→ 03 Software Architecture
→ 04 Distributed Systems
→ 05 Cloud Native
→ 06 Security
→ 07 SRE
→ 08 Business Architecture
→ 09 AI Engineering
→ 10 AI Architecture
```

## 每个能力 README 的固定内容

1. 能力定位
2. 为什么需要
3. 前置能力
4. 核心知识
5. 必须形成的能力
6. 项目任务
7. Test Lab / 实验
8. 常见短板
9. 验收标准
10. 面试迁移
11. 下一阶段关联

## 训练原则

- 知识只是输入
- 完整项目、问题复现、实验、决策和复盘才是能力形成过程
- 没有真实约束时，后续阶段保持 LOCKED
- L3 以上必须有项目证据
