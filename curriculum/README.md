# Curriculum｜能力成长体系

本目录定义“应该具备什么能力”。每个阶段和能力目录都必须有自己的 README，README 不是教材目录，而是一份可执行的成长任务协议。

## 能力结构

```text
Engineering
→ System Design
→ Software Architecture
→ Distributed Systems
→ Cloud Native
→ Security
→ SRE
→ Business Architecture
→ AI Engineering
→ AI Architecture
```

## 每个能力 README 的固定内容

1. 能力定位
2. 为什么需要
3. 前置能力
4. 核心知识
5. 必须形成的能力
6. 项目任务
7. Test Lab / 实验
8. 常见短板
9. 验收标准
10. 面试迁移
11. 下一阶段关联

## 训练原则

知识只是输入，完整项目、问题复现、实验、决策和复盘才是能力形成过程。
