# Interview｜经验迁移式面试

面试训练不以背题为目标，而以真实项目经验的检索、解释、迁移和临场推演为目标。

## 标准路径

```text
面试问题
→ 找到相似历史项目
→ 回忆真实问题
→ 解释根因
→ 说明方案与 Trade-off
→ 根据新约束重新设计
→ 接受追问
```

## 必须能回答

- 你做过什么？
- 项目中遇到过什么问题？
- 如何发现和复现？
- 为什么发生？
- 怎么解决？
- 为什么这样解决？
- 有没有其他方案？
- 方案代价是什么？
- 如果规模扩大 10 倍怎么办？
- 如果核心依赖故障怎么办？
- 这个经验如何迁移到另一个业务？

## 项目映射

每个项目应维护自己的 `interview/`，并逐步建立问题 → 项目 → Experience Card 的映射。
